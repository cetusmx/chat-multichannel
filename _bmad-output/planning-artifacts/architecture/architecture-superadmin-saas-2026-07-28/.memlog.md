- (decision) Auth: Isolate superadmins into a dedicated Superadmin database table and /api/superadmin/auth/login route to prevent privilege escalation.
- (decision) Backend Services: Create a parallel ecosystem of dedicated superadmin services (e.g. superadmin.tenant.service.js) to query data globally without touching existing tenant-scoped services.
- (decision) Hosting: Deploy the Superadmin SPA in a separate Docker container hosted on the same VPS, pointing to a dedicated subdomain.
